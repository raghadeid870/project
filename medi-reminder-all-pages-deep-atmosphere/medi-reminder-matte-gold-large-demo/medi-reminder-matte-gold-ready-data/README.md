# Medi Reminder — Matte Gold + Expanded Demo Data

نسخة مشروع Medi Reminder مع خلفية العيادة والهوية الذهبية المطفيّة ومجموعة بيانات عرض موسّعة.

## التشغيل

المتطلبات: Node.js 18 أو أحدث، وMongoDB محلية أو MongoDB Atlas.

1. فك الضغط وافتح PowerShell داخل المجلد الذي يحتوي مباشرة على `package.json`.
2. جهّز `server/.env` بنسخ `server/.env.example`، ثم اضبط `MONGO_URI` و`JWT_SECRET` (مفتاح عشوائي خاص لا يقل عن 32 حرفاً).
3. ثبّت الاعتماديات:
   ```powershell
   npm install
   ```
4. شغّل المشروع:
   ```powershell
   npm run dev
   ```
5. اترك نافذة PowerShell مفتوحة وافتح `http://localhost:5173`.

## مجموعة البيانات الموسّعة

بعد تسجيل الدخول، اضغط **«إضافة بيانات جاهزة»** في لوحة التحكم. يحاول التطبيق إضافة:

- حتى 14 ملفاً عائلياً.
- 42 تذكيراً/عنصراً.
- 28 موعداً افتراضياً مستقبلياً.
- سجل جرعات لمدة 30 يوماً، أي نحو 1,680 موعد جرعة بحسب جداول التذكير.

قد يقل عدد الملفات المضافة إذا وصل الحساب إلى الحد الأقصى للتطبيق (20 ملفاً). مجموعة العرض مرتبطة بحساب المستخدم الذي سجل دخوله.

### الأمان وعدم التكرار

- البيانات نموذجية للعرض فقط وموسومة بوضوح؛ أسماء العناصر والجرعات ليست أدوية أو جرعات طبية حقيقية.
- لا تستخدم هذه البيانات لتحديد علاج أو جرعة أو لاتخاذ قرار طبي.
- الإضافة لا تحذف بيانات المستخدم الموجودة ولا تستبدلها.
- لكل سجل ضمن مجموعة العرض مفتاح ثابت، لذلك تكرار الضغط لا ينشئ نسخاً مكررة.
- يمكن حذف ملفات العائلة المضافة للعرض من صفحة العائلة؛ حذف الملف يزيل العناصر وسجلات الجرعات والمواعيد المرتبطة به.
- لا تشارك `server/.env` أو `JWT_SECRET` مع أي شخص.

### تشغيل الإضافة من سطر الأوامر (اختياري)

ضع بريد حسابك في `DEMO_EMAIL` داخل `server/.env` ثم نفّذ:
```powershell
npm run seed:demo --workspace=medi-reminder-server
```

## خلفية وتصميم التطبيق

- صورة العيادة محفوظة محلياً في `client/public/medi-healthcare-atmosphere.webp`، فلا تعتمد على خدمة صور خارجية.
- تستخدم الصفحات خلفية العيادة المشتركة مع طبقة تعتيم لتحسين قراءة النصوص.
- الألوان الأساسية: ذهبي شامبين مطفي، أخضر غابي، وتفاصيل برونزية هادئة.
