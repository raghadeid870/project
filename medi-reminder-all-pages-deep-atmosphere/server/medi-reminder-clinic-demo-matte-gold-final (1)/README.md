# Medi Reminder — Full Stack

## التشغيل من المجلد الرئيسي (بعد فك الضغط)

المتطلبات: Node.js 18 أو أحدث، وقاعدة MongoDB محلية أو MongoDB Atlas.

1. افتحي PowerShell داخل المجلد الذي يحتوي على `package.json`.
2. ثبتي جميع المكتبات مرة واحدة:
   ```powershell
   npm install
   ```
3. جهزي ملف إعدادات السيرفر:
   - انسخي `server/.env.example` إلى `server/.env`.
   - ضعي رابط MongoDB في `MONGO_URI`، وقيمة طويلة عشوائية في `JWT_SECRET`.
4. شغلي الواجهة والسيرفر معاً من نفس المجلد:
   ```powershell
   npm run dev
   ```
5. افتحي الواجهة على `http://localhost:5173`.

سيظهر في نفس الطرفية سجل السيرفر والواجهة. لإيقافهما اضغطي `Ctrl+C`.

## تشغيل منفصل عند الحاجة
```powershell
npm run dev:server
npm run dev:client
```
شغلي كل أمر في نافذة PowerShell منفصلة.

## ملاحظات
- لا تشاركي ملف `server/.env` أو أسراره مع الآخرين.
- إذا ظهر خطأ اتصال MongoDB، تأكدي أن `MONGO_URI` صحيح وأن قاعدة البيانات متاحة.


## إضافة بيانات تجريبية للعرض (اختياري)

بعد تسجيل الدخول، استخدمي بطاقة **«إضافة بيانات تجريبية»** في لوحة التحكم. ستضيف إلى حسابك الحالي أربعة ملفات عائلية تجريبية، وتذكيرات شكلية، ومواعيد مستقبلية، وسجل جرعات تجريبي لآخر سبعة أيام حتى تظهر الإحصاءات والرسوم.

- العملية لا تحذف بياناتك الحالية ولا تستبدلها.
- إعادة الضغط لا تنشئ نسخاً مكررة؛ البيانات تُعرّف كمحتوى تجريبي.
- تظهر عبارة «بيانات تجريبية» في أسماء الملفات، ويمكن حذف كل ملف تجريبي من صفحة أفراد العائلة؛ حذف الملف يحذف التذكيرات وسجلات الجرعات والمواعيد المرتبطة به.
- كل الأسماء والتذكيرات والجرعات والمواعيد خيالية للعرض فقط، وليست وصفات أو تعليمات طبية. لا تستخدميها لتنظيم علاج حقيقي.

### خيار سطر الأوامر
يمكن أيضاً ضبط `DEMO_EMAIL` في `server/.env` ليطابق بريد حسابك، ثم تشغيل:
```bash
npm run seed:demo --workspace=medi-reminder-server
```

## تحديث واجهتي العائلة والمواعيد
- صفحة العائلة تعرض ملخصاً لعدد الملفات والملفات المتاحة والمواعيد القادمة.
- بطاقات أفراد العائلة تعرض عدد المواعيد القادمة لكل ملف، مع البحث وتعديل الاسم والحذف.
- صفحة المواعيد تعرض ملخصات اليوم والأسبوع، وتصفية حسب فرد العائلة، وتجميع المواعيد حسب اليوم.
- الإحصاءات المعروضة مستخرجة من الملفات والمواعيد الموجودة في قاعدة البيانات؛ لا تُنشأ بيانات طبية افتراضية.


## تحديث الأجواء والخلفية
- خلفية عامة متعددة التدرجات بألوان sage وmint وأزرق هادئ ولمسات دافئة.
- إبقاء البطاقات بيضاء وواضحة حتى تظل القراءة مريحة.
- تلوين هيدر العائلة والمواعيد وبطاقات الإحصائيات بدرجات باستيل متناسقة.
